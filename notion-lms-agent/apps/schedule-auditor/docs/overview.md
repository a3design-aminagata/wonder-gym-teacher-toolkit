# overview

## 🎯 このツールの位置づけ

schedule-auditor は、  
**LMS（Wonder Gym 講師ポータル）に登録されている「確定スケジュール」**と、  
**ローカルで管理している schedules_enriched.json** を突合し、  
両者の不整合を検出するための「監査専用ツール」です。

このツールは以下を責務とします。

- 正解データを生成しない
- 予定を自動修正しない
- 判定結果をもとに「人が判断できる状態」を作る

あくまで **差分検出・可視化に特化**した存在です。

---

## 🧭 立ち位置（全体構成の中で）

- Notion / LMS / JSON はそれぞれ独立したデータ源
- どれか一つを「絶対正」とはしない
- schedule-auditor は「突合による異常検知」を行う

つまり、

- 「LMS にあるが JSON に無い」
- 「JSON にあるが LMS に無い」
- 「日付・時刻・地域・開講月が食い違っている」

といった **状態のズレを明示するレイヤー**です。

---

## 🔍 監査対象の粒度

このツールでは、授業 1 コマを以下の情報で一意に判定します。

- 日付（YYYY-MM-DD）
- 時刻（HH:MM）
- 地域（例：千葉、山口）
- 開講月（例：7 月開講）
